Classify this single book page.

Return `is_comic_page=true` only when the page contains readable manga panels.
Use these page types:

- comic: manga panels with dialogue or sequential action
- cover: front or back cover
- illustration: a single illustration without sequential panels
- character_intro: profile cards or character introductions
- afterword: prose-heavy author commentary
- colophon: publisher, ISBN, printing, or release metadata
- blank: blank page or page number only
- unknown: insufficient evidence

Do not classify a page as non-comic merely because it appears near a cover.
Use the visible layout, not the page's expected position in the book.
